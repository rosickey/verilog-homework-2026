# HW01 说明 — 240210117 乐奕子豪

方波激励下 CD4017 十进制计数器的仿真。

## 文件

| 文件 | 说明 |
| --- | --- |
| `clk_gen.v` | 课堂订正版时钟模块，50 MHz 方波（半周期 10 ns，整周期 20 ns） |
| `cd4017.v` | 十进制计数器：`clr` 异步清零、`en` 高有效使能、`q[9:0]` 一位热码输出、`carry_out` 进位 |
| `top_tb.v` | 测试平台，同时例化 `clk_gen` 与 `cd4017` |
| `report.png` | 仿真波形（由 `report.vcd` 绘制） |
| `run.cmd` | 双击即编译 + 仿真 + 重画波形 |

## 设计要点

- 计数器用 4 位寄存器 `count`（0–9），`q = 10'b1 << count`，任一时刻只有一位为高，
  与 CD4017 的 Q0–Q9 译码输出一致；`q[9]` 之后回到 `q[0]`，即十进制循环。
- `clr` 高电平异步清零，`en = 0` 时计数保持，优先级为 `clr` > `en`。
- `carry_out` 在 `count == 9` 时为高，即每 10 个时钟给出一拍进位。
  > 若老师要求与数据手册一致（CO 在 Q0–Q4 期间为高、用于级联），把
  > `assign carry_out = (count == 4'd9);` 改成 `assign carry_out = (count <= 4'd4);`

## 仿真时序

| 时间 | 动作 |
| --- | --- |
| 0 ns | `clr = 1, en = 0`，异步清零，`q = 10'b0000000001` |
| 25 ns | 释放 `clr`，`en = 1`，开始计数 |
| 25–425 ns | 20 个时钟，走完 2 个完整循环（Q0→Q9→Q0） |
| 425–485 ns | `en = 0` 暂停 60 ns，`q` 保持不变 |
| 485–700 ns | `en = 1` 恢复计数 |
| 700 ns | `$finish` |

## 运行

### 方式一：双击 `run.cmd`

本机已装好 Icarus Verilog（`tools\iverilog`），脚本会自动编译、仿真、生成
`report.vcd` 并重画 `report.png`。

### 方式二：命令行

```bash
iverilog -g2012 -Wall -o simv.exe clk_gen.v cd4017.v top_tb.v
vvp simv.exe
gtkwave report.vcd          # 需要 GTKWave，截图另存为 report.png
```

### 方式三：Vivado / ModelSim

新建工程，把三个 `.v` 加入，顶层设 `top_tb`，仿真运行 700 ns 以上，
把 `clk / clr / en / q[9:0] / carry_out` 拖进波形窗口后截图。

## 波形怎么看

- `clk`：周期 20 ns，`clr` 释放后开始跳变；
- `q`：高电平沿 Q0→Q1→…→Q9 逐位左移，第 10 个时钟回到 Q0；
- `carry_out`：在 Q9 那一个周期为高（图中约 190、390、650 ns 处）；
- `en = 0` 的黄色区间内，`q` 冻结不动，说明使能端有效。
